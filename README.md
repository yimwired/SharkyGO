# SharkyGo - README

## ภาพรวมของเกม
SharkyGo เป็นเกม 2D แนวเลื่อนด้านข้างที่พัฒนาโดยใช้ Kivy Framework โดยผู้เล่นจะควบคุมน้องฉลามเพื่อหลบหลีกสิ่งกีดขวาง และเก็บคะแนนให้ได้มากที่สุด เกมนี้มีการเปลี่ยนฉากพื้นหลังเมื่อผ่านคะแนนที่กำหนด รวมถึงเสียงประกอบที่สร้างบรรยากาศให้สนุกยิ่งขึ้น

## คุณสมบัติของเกม
- **หน้าเมนู**: สามารถเริ่มเกมและปรับระดับเสียงได้
- **ฉากหลังเปลี่ยนแปลงตามระดับคะแนน**
- **ความเร็วสิ่งกีดขวางเพิ่มขึ้นเมื่อเล่นไปนานขึ้น**
- **เอฟเฟกต์เสียงและเพลงประกอบ**
- **ด่านที่หลากหลาย**: เปลี่ยนจากมหาสมุทรเป็นโขดหิน และเปลี่ยนเป็นน้ำแข็งเมื่อผ่านระดับที่กำหนด
- **ระบบนับคะแนน**: แสดงผลคะแนนของผู้เล่น

## การติดตั้ง
### สิ่งที่ต้องมี
ติดตั้ง Python และ Kivy ก่อน
```sh
pip install kivy
```

### วิธีการรันเกม
1. ดาวน์โหลดหรือคัดลอกไฟล์โปรเจกต์
2. ไปที่โฟลเดอร์ของโปรเจกต์
3. รันคำสั่งนี้:
```sh
python main.py
```

## วิธีเล่น
- กด **Spacebar** เพื่อทำให้ฉลามกระโดด
- หลีกเลี่ยงสิ่งกีดขวาง (ต้นสาหร่าย, โขดหิน, และน้ำแข็ง)
- เมื่อคะแนนถึง **30** จะเปลี่ยนฉากเป็นโขดหิน และเพิ่มความเร็ว
- เมื่อคะแนนถึง **55** จะเปลี่ยนฉากเป็นน้ำแข็ง มีเสียงเพลงใหม่ และความเร็วเพิ่มขึ้น
- หากชนสิ่งกีดขวางหรือตกขอบจอ เกมจะจบลง
- กดคลิกหรือ Spacebar หลังจากแพ้เพื่อเริ่มเกมใหม่

## โครงสร้างโค้ด
### `main.py`
- **MenuScreen**: จัดการหน้าเมนู และการปรับระดับเสียง
- **GameScreen**: จัดการการอัปเดตเฟรมเกม
- **SharkyGoGame**: ควบคุมการเล่นของเกม การชน และการเปลี่ยนระดับ
- **Shark**: ตัวละครหลักที่ใช้แรงโน้มถ่วงในการเคลื่อนที่
- **Pipe**: วัตถุที่เป็นอุปสรรคเคลื่อนที่จากขวาไปซ้าย
- **SharkyGoApp**: ควบคุมหน้าจอ และเริ่มต้นเกม

### `sharkygo.kv`
กำหนดองค์ประกอบ UI เช่น:
- เมนูเกม (ปุ่มเริ่มเกม, ปุ่มออกจากเกม, ตัวเลื่อนปรับเสียง)
- หน้าจอเกม (ตัวละคร, สิ่งกีดขวาง, คะแนน, หน้าจอ Game Over)

## ทรัพยากรที่ใช้ในเกม
- **รูปภาพ**: พื้นหลังของแต่ละด่าน, อุปสรรค, ตัวละครฉลาม
- **เสียง**: เพลงพื้นหลัง (`BackgroundMermaid.mp3`, `BackgroundEpic.mp3`), เสียงกระโดด (`jump.mp3`), และเสียงชน (`hitcute.mp3`)

## การพัฒนาในอนาคต
- เพิ่มพลังพิเศษ (เช่น ไร้เทียมทาน, เพิ่มความเร็ว)
- เพิ่มระบบจัดอันดับคะแนนสูงสุด
- เพิ่มอุปสรรคที่มีความหลากหลายมากขึ้น
